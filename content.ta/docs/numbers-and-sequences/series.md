# 2.8 தொடர்கள் (Series)

ஒரு தொடர்வரிசையின் உறுப்புகளின் கூடுதல் தொடர் எனப்படும். \( a_1, a_2, a_3, \dots, a_n, \dots \) என்பது ஒரு மெய்யெண் தொடர்வரிசை என்க. இங்கு \( a_1 + a_2 + a_3 + \cdots \) என்பது மெய்யெண் தொடர் ஆகும்.

ஒரு தொடரில் முடிவுறு எண்ணிக்கையில் உறுப்புகள் அமையுமானால் அது முடிவுறு தொடர் எனப்படும். ஒரு தொடரில் முடிவுறா எண்ணிக்கையில் உறுப்புகள் அமையுமானால் அது முடிவுறாத் தொடர் எனப்படும். நாம் இங்கு முடிவுறு தொடர்களை மட்டுமே விவாதிப்போம்.

## 2.8.1 ஒரு கூட்டுத் தொடர்வரிசையின் முதல் n உறுப்புகளின் கூடுதல் (Sum to n terms of an A.P.)

ஒரு தொடரின் உறுப்புகள் கூட்டுத் தொடர்வரிசையில் அமையுமானால் அத்தொடர் கூட்டுத் தொடர் எனப்படும்.

\( a, a + d, a + 2d, a + 3d, \dots \) என்பது ஒரு கூட்டுத் தொடர்வரிசை என்க.

ஒரு கூட்டுத் தொடர்வரிசையின் முதல் n உறுப்புகளின் கூடுதல் ஆனது \( S_n \) எனக் குறிப்பிடப்படுகிறது.

\[
S_n = a + (a + d) + (a + 2d) + \cdots + (a + (n-1)d) \quad \dots (1)
\]

மேற்கண்ட தொடர்வரிசையைக் கடைசியிலிருந்து தலைகீழாக எழுத நாம் பெறுவது,

\[
S_n = (a + (n-1)d) + (a + (n-2)d) + \cdots + (a + d) + a \quad \dots (2)
\]

(1) மற்றும் (2) ஐக் கூட்ட நாம் பெறுவது,

\[
2S_n = [a + a + (n-1)d] + [a + d + a + (n-2)d] + \cdots + [a + (n-2)d + a + d] + [a + (n-1)d + a]
\]

\[
2S_n = [2a + (n-1)d] + [2a + (n-1)d] + \cdots + [2a + (n-1)d] \quad \text{(n உறுப்புகள்)}
\]

\[
2S_n = n \times [2a + (n-1)d]
\]

\[
S_n = \frac{n}{2}[2a + (n-1)d]
\]

## குறிப்பு

ஒரு கூட்டுத் தொடரின் முதல் உறுப்பு a மற்றும் கடைசி உறுப்பு l (nth-வது உறுப்பு) கொடுக்கப்பட்டிருந்தால்,

\[
S_n = \frac{n}{2}[2a + (n-1)d] = \frac{n}{2}[a + a + (n-1)d]
\]

\[
S_n = \frac{n}{2}[a + l]
\]

(ஏனெனில், \( l = a + (n-1)d \))

## முன்னேற்றச் சோதனை

1. ஒரு தொடர் வரிசையிலுள்ள உறுப்புகளின் கூடுதல்

2. ஒரு தொடரில் முடிவுறு எண்ணிக்கையில் உறுப்புகள் அமையுமானால் அது எனப்படும்.

3. ஒரு தொடரின் உறுப்புகள் ___________யில் அமைந்தால் அத்தொடர் ஒரு கூட்டுத்தொடர் எனப்படும்.

4. ஒரு கூட்டுத் தொடரின் முதல் உறுப்பு மற்றும் கடைசி உறுப்பு கொடுக்கப்பட்டால் முதல் n உறுப்புகளின் கூடுதல் காணும் சூத்திரம் _________.

## எடுத்துக்காட்டு 2.31

\( 8, 7\frac{1}{4}, 6\frac{1}{2}, 5\frac{3}{4}, \dots \) என்ற கூட்டுத் தொடர்வரிசையின் முதல் 15 உறுப்புகளின் கூடுதல் காண்க.

**தீர்வு** இங்கு முதல் உறுப்பு \( a = 8 \), பொது வித்தியாசம்

\[
d = 7\frac{1}{4} - 8 = -\frac{3}{4}
\]

கூட்டுத் தொடர்வரிசையின் முதல் n உறுப்புகளின் கூடுதல்

\[
S_n = \frac{n}{2}[2a + (n-1)d]
\]

\[
S_{15} = \frac{15}{2} \left[2 \times 8 + (15-1)\left(-\frac{3}{4}\right)\right]
\]

\[
S_{15} = \frac{15}{2} \left[16 - \frac{21}{2}\right] = \frac{165}{4}
\]

## எடுத்துக்காட்டு 2.32

\( 0.40 + 0.43 + 0.46 + \cdots + 1 \) என்ற தொடரின் கூடுதல் காண்க.

**தீர்வு** இங்கு, \( a = 0.40 \) மற்றும் \( l = 1 \), \( d = 0.43 - 0.40 = 0.03 \).

ஆகவே,

\[
n = \frac{l - a}{d} + 1 = \frac{1 - 0.40}{0.03} + 1 = 21
\]

ஒரு கூட்டுத் தொடர்வரிசையின் முதல் n உறுப்புகளின் கூடுதல்,

\[
S_n = \frac{n}{2}[a + l]
\]

இங்கு, \( n = 21 \). எனவே

\[
S_{21} = \frac{21}{2}[0.40 + 1] = 14.7
\]

ஆகவே கூட்டுத் தொடரின் 21 உறுப்புகளின் கூடுதல் 14.7 ஆகும்.

## எடுத்துக்காட்டு 2.33

\( 1 + 5 + 9 + \cdots + 81 \) என்ற தொடரின் கூடுதல் காண்க.

**தீர்வு** இங்கு, \( a = 1, l = 81, d = 5 - 1 = 4 \).

\[
n = \frac{l - a}{d} + 1 = \frac{81 - 1}{4} + 1 = 21
\]

\[
S_{21} = \frac{21}{2}[1 + 81] = 861
\]

## எடுத்துக்காட்டு 2.34

\( 0.6 + 0.7 + 0.8 + \cdots + 2.0 \) என்ற தொடரின் கூடுதல் காண்க.

**தீர்வு** இங்கு, \( a = 0.6, l = 2.0, d = 0.1 \).

\[
n = \frac{2.0 - 0.6}{0.1} + 1 = 15
\]

\[
S_{15} = \frac{15}{2}[0.6 + 2.0] = 19.5
\]

## எடுத்துக்காட்டு 2.35

ஒரு கூட்டுத் தொடர்வரிசையில், \( S_n = 3n^2 + 2n \) எனில்,

(i) அத்தொடர்வரிசையின் முதல் உறுப்பு

(ii) பொது வித்தியாசம்

(iii) n-வது உறுப்பு ஆகியவற்றைக் காண்க.

**தீர்வு** (i) \( S_n = 3n^2 + 2n \)

\( S_1 = 3(1)^2 + 2(1) = 5 \)

எனவே, முதல் உறுப்பு \( a = 5 \).

(ii) \( S_2 = 3(2)^2 + 2(2) = 16 \)

\( S_2 = t_1 + t_2 = 16 \Rightarrow 5 + t_2 = 16 \Rightarrow t_2 = 11 \)

பொது வித்தியாசம் \( d = t_2 - t_1 = 11 - 5 = 6 \).

(iii) \( t_n = S_n - S_{n-1} \)

\( S_n = 3n^2 + 2n \)

\( S_{n-1} = 3(n-1)^2 + 2(n-1) = 3(n^2 - 2n + 1) + 2n - 2 = 3n^2 - 6n + 3 + 2n - 2 = 3n^2 - 4n + 1 \)

\( t_n = (3n^2 + 2n) - (3n^2 - 4n + 1) = 6n - 1 \)

## எடுத்துக்காட்டு 2.36

300-க்கும் 600-க்கும் இடையே 7-ஆல் வகுபடும் இயல் எண்களின் கூடுதல் காண்க.

**தீர்வு** 300-க்கும் 600-க்கும் இடையே 7-ஆல் வகுபடும் இயல் எண்கள் 301, 308, 315, …, 595.

300-க்கும் 600-க்கும் இடையே 7-ஆல் வகுபடும் இயல் எண்களின் கூடுதல் \( 301 + 308 + 315 + \cdots + 595 \).

மேற்கண்ட தொடரின் உறுப்புகள் கூட்டுத் தொடர்வரிசையில் அமைந்துள்ளன.

முதல் உறுப்பு \( a = 301 \); பொது வித்தியாசம் \( d = 7 \); கடைசி உறுப்பு \( l = 595 \).

\[
n = \frac{l - a}{d} + 1 = \frac{595 - 301}{7} + 1 = 43
\]

\( S_n = \frac{n}{2}[a + l] \), என்பதால்

\[
S_{43} = \frac{43}{2}[301 + 595] = 19264
\]

## எடுத்துக்காட்டு 2.37

சிறிய தரையோடுகளைக் கொண்டு 12 அடி பக்க அளவுள்ள சமபக்க முக்கோண தரையோடுகள் (Mosaic) அமைக்கப்படுகிறது. அவற்றில் உள்ள ஒவ்வொரு தரையோடும் 12 அங்குல அளவிலான சமபக்க முக்கோண வடிவில் உள்ளது. சிறிய தரையோடுகளின் வண்ணங்கள் படத்தில் காண்பிக்கப்பட்டுள்ளது போல மாறி மாறி உள்ளன. ஒவ்வொரு வண்ணத்திலும் உள்ள தரையோடுகளின் எண்ணிக்கை மற்றும் கொடுக்கப்பட்ட அமைப்பில் உள்ள மொத்த தரையோடுகளின் எண்ணிக்கை காண்க.

**தீர்வு** தரையோடுகள் ஆனது 12 அடி பக்க அளவுள்ள சமபக்க முக்கோணமாகவும் மற்றும் ஒவ்வொரு சிறிய தரையோடும் 12 அங்குல (1 அடி) பக்க அளவுள்ள சமபக்க முக்கோணமாகவும் இருப்பதால், இந்த அமைப்பில் வரிசைகளில் சிறிய தரையோடுகள் அடுக்கப்பட்டிருக்கின்றன.

படத்திலிருந்து ஒவ்வொரு வரிசையிலும் உள்ள வெள்ளை நிற தரையோடுகளின் எண்ணிக்கை 1, 2, 3, 4, ..., 12 என்பது ஒரு கூட்டுத் தொடர்வரிசை என அறியலாம்.

இதுபோல ஒவ்வொரு வரிசையிலும் உள்ள நீல நிற தரையோடுகளின் எண்ணிக்கை 0, 1, 2, 3, ..., 11. இதுவும் ஒரு கூட்டுத் தொடர் வரிசையாகும்.

வெள்ளை நிற தரையோடுகளின் எண்ணிக்கை

\[
= 1 + 2 + 3 + \cdots + 12 = \frac{12}{2}[1 + 12] = 78
\]

நீல நிற தரையோடுகளின் எண்ணிக்கை

\[
= 0 + 1 + 2 + 3 + \cdots + 11 = \frac{12}{2}[0 + 11] = 66
\]

மொத்த தரையோடுகளின் எண்ணிக்கை

\[
= 78 + 66 = 144
\]

## எடுத்துக்காட்டு 2.38

ஒரு தெருவிலுள்ள வீடுகளுக்கு 1 முதல் 49 வரை தொடர்ச்சியாகக் கதவிலக்கம் வழங்கப்பட்டுள்ளது. செந்திலின் வீட்டிற்கு முன்னதாக உள்ள வீடுகளின் கதவிலக்கங்களின் கூடுத்தொகையானது செந்திலின் வீட்டிற்குப் பின்னதாக உள்ள வீடுகளின் கதவிலக்கங்களின் கூடுத்தொகைக்குச் சமம் எனில் செந்திலின் வீட்டின் கதவிலக்கத்தைக் காண்க.

**தீர்வு** செந்திலின் வீட்டின் கதவிலக்கம் x என்க.

\[
1 + 2 + 3 + \cdots + (x-1) = (x+1) + (x+2) + \cdots + 49
\]

\[
1 + 2 + 3 + \cdots + (x-1) = [1 + 2 + 3 + \cdots + 49] - [1 + 2 + 3 + \cdots + x]
\]

\[
\frac{x-1}{2}[1 + (x-1)] = \frac{49}{2}[1 + 49] - \frac{x}{2}[1 + x]
\]

\[
\frac{x(x-1)}{2} = \frac{49 \times 50}{2} - \frac{x(x+1)}{2}
\]

\[
x^2 - x = 2450 - x^2 - x
\]

\[
2x^2 = 2450
\]

\[
x^2 = 1225
\]

\[
x = 35
\]

எனவே, செந்திலின் வீட்டின் கதவிலக்கம் 35 ஆகும்.

## எடுத்துக்காட்டு 2.39

\( S_1, S_2 \) மற்றும் \( S_3 \) என்பன முறையே ஒரு கூட்டுத் தொடர்வரிசையின் முதல் n, 2n மற்றும் 3n உறுப்புகளின் கூடுதல் ஆகும். \( S_3 = 3(S_2 - S_1) \) என நிறுவுக.

**தீர்வு** \( S_1, S_2 \) மற்றும் \( S_3 \) என்பன முறையே ஒரு கூட்டுத் தொடர்வரிசையின் முதல் n, 2n மற்றும் 3n உறுப்புகளின் கூடுதல் எனில்,

\[
S_1 = \frac{n}{2}[2a + (n-1)d]
\]

\[
S_2 = \frac{2n}{2}[2a + (2n-1)d]
\]

\[
S_3 = \frac{3n}{2}[2a + (3n-1)d]
\]

தற்போது,

\[
S_2 - S_1 = \frac{2n}{2}[2a + (2n-1)d] - \frac{n}{2}[2a + (n-1)d]
\]

\[
= \frac{n}{2}[(4a + 2(2n-1)d] - [2a + (n-1)d]]
\]

\[
S_2 - S_1 = \frac{n}{2} \times [2a + (3n-1)d]
\]

\[
3(S_2 - S_1) = \frac{3n}{2}[2a + (3n-1)d]
\]

\[
3(S_2 - S_1) = S_3
\]

11. \( S_1, S_2, S_3, \dots, S_m \) என்பன m வெவ்வேறு கூட்டுத் தொடர்வரிசைகளின் n உறுப்புகளின் கூடுதலாகும். முதல் உறுப்புகள் 1, 2, 3, ..., m மற்றும் பொது வித்தியாசங்கள் 1, 3, 5, ..., (2m − 1) முறையே அமைந்தால், அந்த கூட்டுத் தொடர் வரிசைகளில் \( S_1 + S_2 + S_3 + \cdots + S_m = \frac{mn(mn+1)}{2} \) என நிரூபிக்க.
