## If the sequence $t_1, t_2, t_3, \dots$ is an A.P., then the sequence $t_6, t_{12}, t_{18}, \dots$ is :

---

#### Let the original A.P. have common difference $d$. The $n$-th term is $t_n = a + (n-1)d$.
- $t_6 = a + 5d$
- $t_{12} = a + 11d$
- $t_{18} = a + 17d$

The difference between consecutive terms:
$t_{12} - t_6 = (a + 11d) - (a + 5d) = 6d$
$t_{18} - t_{12} = (a + 17d) - (a + 11d) = 6d$

Since the common difference $6d$ is constant, the sequence $t_6, t_{12}, t_{18}, \dots$ is an Arithmetic Progression (A.P.).
