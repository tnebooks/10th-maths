## Which of the following should be added to make $x^4 + 64$ a perfect square ?

---

#### Rewrite $x^4 + 64$ as $(x^2)^2 + 8^2$.

Using the algebraic identity $(a + b)^2 = a^2 + 2ab + b^2$ with $a = x^2$ and $b = 8$:

<div class="math-display">$$(x^2 + 8)^2 = (x^2)^2 + 2(x^2)(8) + 8^2 = x^4 + 16x^2 + 64$$</div>


Thus, the term that must be added is $2(x^2)(8) = 16x^2$.
