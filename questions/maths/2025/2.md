## Let $n(A) = m$ and $n(B) = n$, then the total number of functions that exist from $B$ to $A$ is :

---

#### A function from set $B$ to set $A$ assigns to each element of $B$ exactly one element of $A$.
Since $n(A) = m$, each of the $n$ elements in $B$ has $m$ possible images in $A$.

By the fundamental counting principle, the total number of functions is $m \times m \times \dots \times m$ ($n$ times) $= m^n$.
