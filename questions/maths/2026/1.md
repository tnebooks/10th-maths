## If $\{(a, 8), (6, b)\}$ represents an identity function, then the value of $a$ and $b$ are respectively :

---

#### An identity function $I(x) = x$ maps every element to itself, i.e., each ordered pair is of the form $(x, x)$.
- $(a, 8) \implies a = 8$
- $(6, b) \implies b = 6$

Therefore, $(a, b) = (8, 6)$.
