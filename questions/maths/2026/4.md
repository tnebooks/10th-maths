## The value of $(1^3 + 2^3 + 3^3 + \dots + 15^3) - (1 + 2 + 3 + \dots + 15)$ is :

---

#### Using standard summation formulas for $n = 15$:
- $\sum_{i=1}^{15} i = \frac{15 \times 16}{2} = 120$
- $\sum_{i=1}^{15} i^3 = \left(\frac{15 \times 16}{2}\right)^2 = 120^2 = 14400$


<div class="math-display">$$(1^3 + 2^3 + \dots + 15^3) - (1 + 2 + \dots + 15) = 14400 - 120 = 14280$$</div>
