## If $A$ is a $2\times3$ matrix and $B$ is a $3\times4$ matrix, how many columns does $AB$ have

---

#### If matrix $A$ is of order $m\times n$ ($2\times3$) and matrix $B$ is of order $n\times p$ ($3\times4$), the matrix product $AB$ is defined and has order $m\times p = 2\times4$. The number of columns in $AB$ is the second dimension, which is 4.
