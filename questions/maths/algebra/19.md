## Which of the following can be calculated from the given matrices $A=\begin{pmatrix}1&2\\3&4\\5&6\end{pmatrix}$, $B=\begin{pmatrix}1&2&3\\4&5&6\\7&8&9\end{pmatrix}$, (i) $A^2$ (ii) $B^2$ (iii) $AB$ (iv) $BA$.

---

#### Matrix $A$ has order $3\times2$ and matrix $B$ has order $3\times3$. Matrix multiplication $XY$ requires the number of columns in $X$ to equal the number of rows in $Y$. For $A^2$ ($3\times2$ with $3\times2$) and $AB$ ($3\times2$ with $3\times3$), columns of the first (2) $\ne$ rows of the second (3), so they are undefined. For $B^2$ ($3\times3$ with $3\times3$) and $BA$ ($3\times3$ with $3\times2$), the inner dimensions match (3 = 3), so they can be calculated. Hence, only (ii) and (iv) can be calculated.
