## In $\triangle LMN$, $\angle L=60^\circ$, $\angle M=50^\circ$. If $\triangle LMN\sim\triangle PQR$ then the value of $\angle R$ is

---

#### In $\triangle LMN$, the sum of the three interior angles is $180^\circ$:
$$\angle L + \angle M + \angle N = 180^\circ \implies 60^\circ + 50^\circ + \angle N = 180^\circ \implies \angle N = 180^\circ - 110^\circ = 70^\circ$$
Since $\triangle LMN \sim \triangle PQR$, corresponding angles of similar triangles are equal:
$$\angle R = \angle N = 70^\circ$$
