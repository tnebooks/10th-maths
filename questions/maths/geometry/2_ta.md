## $\triangle LMN$-யில் $\angle L=60^\circ$, $\angle M=50^\circ$. மேலும், $\triangle LMN \sim \triangle PQR$ எனில், $\angle R$-யின் மதிப்பு

---

#### $\triangle LMN$-யில் முக்கோணத்தின் மூன்று கோணங்களின் கூடுதல் $180^\circ$ ஆகும்:
$$\angle L + \angle M + \angle N = 180^\circ \implies 60^\circ + 50^\circ + \angle N = 180^\circ \implies \angle N = 180^\circ - 110^\circ = 70^\circ$$
$\triangle LMN \sim \triangle PQR$ என்பதால், வடிவொத்த முக்கோணங்களின் ஒத்த கோணங்கள் சமம்:
$$\angle R = \angle N = 70^\circ$$
