## If $A = 2^{65}$ and $B = 2^{64} + 2^{63} + 2^{62} + \cdots + 2^0$ which of the following is true?

---

#### $B = 2^0 + 2^1 + 2^2 + \cdots + 2^{64}$ is the sum of a Geometric Progression with 65 terms, first term $a = 1$, and common ratio $r = 2$. Using the G.P. sum formula:
$B = \frac{1(2^{65} - 1)}{2 - 1} = 2^{65} - 1$.
Since $A = 2^{65}$, we see that $A - B = 2^{65} - (2^{65} - 1) = 1$. Hence, $A$ is larger than $B$ by 1.
