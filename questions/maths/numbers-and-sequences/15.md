## The value of $(1^3 + 2^3 + 3^3 + \cdots + 15^3) - (1 + 2 + 3 + \cdots + 15)$ is

---

#### We know that $\sum_{k=1}^n k = \frac{n(n+1)}{2}$ and $\sum_{k=1}^n k^3 = \left[\frac{n(n+1)}{2}\right]^2$.
For $n = 15$:
$1 + 2 + \cdots + 15 = \frac{15 \times 16}{2} = 120$.
$1^3 + 2^3 + \cdots + 15^3 = 120^2 = 14400$.
Therefore, $(1^3 + 2^3 + \cdots + 15^3) - (1 + 2 + \cdots + 15) = 14400 - 120 = 14280$.
