## \((1^3 + 2^3 + 3^3 + \dots + 15^3) - (1 + 2 + 3 + \dots + 15)\) யின் மதிப்பு

---

#### \(1 + 2 + \dots + 15 = \frac{15 \times 16}{2} = 120\).
\(1^3 + 2^3 + \dots + 15^3 = \left(\frac{15 \times 16}{2}\right)^2 = 120^2 = 14400\).
எனவே, \((1^3 + 2^3 + \dots + 15^3) - (1 + 2 + \dots + 15) = 14400 - 120 = 14280\) ஆகும்.
