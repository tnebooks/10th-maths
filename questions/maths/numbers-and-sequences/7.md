## Given $F_1 = 1$, $F_2 = 3$ and $F_n = F_{n-1} + F_{n-2}$ then $F_5$ is

---

#### Using the recurrence relation $F_n = F_{n-1} + F_{n-2}$:
- $F_3 = F_2 + F_1 = 3 + 1 = 4$
- $F_4 = F_3 + F_2 = 4 + 3 = 7$
- $F_5 = F_4 + F_3 = 7 + 4 = 11$.
Hence, $F_5 = 11$.
