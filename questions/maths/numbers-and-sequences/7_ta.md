## \(F_1 = 1, F_2 = 3\) மற்றும் \(F_n = F_{n-1} + F_{n-2}\) எனக் கொடுக்கப்படின் \(F_5\) ஆனது

---

#### கொடுக்கப்பட்ட தொடர்பைப் பயன்படுத்தி:
- \(F_3 = F_2 + F_1 = 3 + 1 = 4\)
- \(F_4 = F_3 + F_2 = 4 + 3 = 7\)
- \(F_5 = F_4 + F_3 = 7 + 4 = 11\).
எனவே, \(F_5 = 11\) ஆகும்.
