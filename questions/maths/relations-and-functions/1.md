## If $n(A \times B) = 6$ and $A = \{1,3\}$ then $n(B)$ is

---

#### We know that $n(A \times B) = n(A) \times n(B)$. Given $A = \{1,3\}$, the number of elements in set $A$ is $n(A) = 2$. Since $n(A \times B) = 6$, we have $2 \times n(B) = 6 \implies n(B) = \frac{6}{2} = 3$.
