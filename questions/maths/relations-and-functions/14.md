## If $g = \{(1,1),(2,3),(3,5),(4,7)\}$ is a function given by $g(x) = \alpha x + \beta$ then the values of $\alpha$ and $\beta$ are

---

#### Using the ordered pairs in $g(x) = \alpha x + \beta$:
For $(1,1)$: $\alpha(1) + \beta = 1 \implies \alpha + \beta = 1$.
For $(2,3)$: $\alpha(2) + \beta = 3 \implies 2\alpha + \beta = 3$.
Subtracting the first equation from the second gives $\alpha = 2$. Substituting $\alpha = 2$ gives $2 + \beta = 1 \implies \beta = -1$. Thus, $(\alpha, \beta) = (2,-1)$.
