## If there are 1024 relations from a set $A = \{1, 2, 3, 4, 5\}$ to a set $B$, then the number of elements in $B$ is

---

#### The total number of relations from set $A$ to set $B$ is given by $2^{n(A) \times n(B)}$. Here, $n(A) = 5$. Let $n(B) = k$. Then $2^{5k} = 1024$. Since $1024 = 2^{10}$, we have $5k = 10 \implies k = 2$. Thus, the number of elements in $B$ is 2.
