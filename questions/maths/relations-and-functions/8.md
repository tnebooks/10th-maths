## If $\{(a,8),(6,b)\}$ represents an identity function, then the value of $a$ and $b$ are respectively

---

#### An identity function maps every element to itself, meaning $f(x) = x$ for every ordered pair $(x, x)$. For $(a, 8)$ to be in an identity function, $a = 8$. For $(6, b)$ to be in an identity function, $b = 6$. Hence, $(a, b) = (8, 6)$.
