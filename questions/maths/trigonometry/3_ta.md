## $(\sin\alpha+\text{cosec}\,\alpha)^2+(\cos\alpha+\sec\alpha)^2 = k+\tan^2\alpha+\cot^2\alpha$ எனில் $k$ –ன் மதிப்பு

---

#### இரு வர்க்கக் கோவைகளையும் விரிக்க:
$$(\sin\alpha + \text{cosec}\,\alpha)^2 = \sin^2\alpha + \text{cosec}^2\alpha + 2$$
$$(\cos\alpha + \sec\alpha)^2 = \cos^2\alpha + \sec^2\alpha + 2$$
இரண்டையும் கூட்ட:
$$(\sin^2\alpha + \cos^2\alpha) + 4 + (1 + \cot^2\alpha) + (1 + \tan^2\alpha) = 1 + 4 + 1 + 1 + \tan^2\alpha + \cot^2\alpha = 7 + \tan^2\alpha + \cot^2\alpha$$
எனவே, $k = 7$ ஆகும்.
