## If $\sin\theta + \cos\theta = a$ and $\sec\theta + \text{cosec}\,\theta = b$, then the value of $b(a^2-1)$ is equal to

---

#### Squaring $a = \sin\theta + \cos\theta$:
$$a^2 = (\sin\theta + \cos\theta)^2 = \sin^2\theta + \cos^2\theta + 2\sin\theta\cos\theta = 1 + 2\sin\theta\cos\theta$$
$$a^2 - 1 = 2\sin\theta\cos\theta$$
Now for $b$:
$$b = \sec\theta + \text{cosec}\,\theta = \frac{1}{\cos\theta} + \frac{1}{\sin\theta} = \frac{\sin\theta + \cos\theta}{\sin\theta\cos\theta} = \frac{a}{\sin\theta\cos\theta}$$
Multiplying $b$ by $(a^2 - 1)$:
$$b(a^2 - 1) = \frac{a}{\sin\theta\cos\theta} \times (2\sin\theta\cos\theta) = 2a$$
